# Private Pilot Flashcards

Exam-format practice for the FAA Private Pilot (Airplane) knowledge test: 625 three-choice questions, including the 61 questions of the FAA published sample exam with their figures from the FAA testing supplement (FAA-CT-8080-2H).

Open it here: https://psette.github.io/ppl-flashcards/

Progress is saved in the browser. Use the Progress tab to copy a code between devices.
